## 回退与撤销

- 使用 Git 提交历史定位目标版本；原始 V1.0 文件备份为 `history/index_V1.0.html`。
- 回退已推送的版本时保留共享历史，通过新的回退提交恢复，不改写远端历史。
- 让 AI 重做：说明要基于哪个 Git 提交、标签或文件，以及具体需求；保留其他已认可改动。

回退文件会恢复该版本的界面和逻辑，不会自动恢复或清除浏览器保存的工程师记录。
