# PPR 质量分析助手 · AI 迭代与回退包

把整个 ZIP 交给 Claude 或其他 AI，并发送这一句：

> 请先阅读包内 AGENTS.md，按其约束迭代；本轮基线是 index.html，我要修改：〔写具体需求〕。保留原版，另存新版本，并交付保留历史版本的完整 ZIP。

后续修改时，把“index.html”替换为你已经满意的版本文件名即可。
若 AI 无法读取 ZIP，解压后把 AGENTS.md、README.md 和指定 HTML 一起提供给它。

## 不满意时怎么回退

- 直接重新打开上一版 HTML，原文件一直保留。
- 回到最初版本：打开“history/index_V1.0.html”。
- 让 AI 重做：发送“上一轮先不用，请从 index_V1.0.html 重新修改：〔需求〕，保留所有旧版本”。
- 只撤销一部分：发送“基于 index_V1.1.html，只撤销〔具体改动〕，其他已认可内容保持原样，另存新版本”。

回退文件会恢复该版本的界面和逻辑，不会自动恢复或清除浏览器保存的工程师记录。
